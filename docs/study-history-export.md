# Экспорт истории тренировок — 19.11.2026

В Настройках → Мои данные появились два CSV: список тренировок и ответы по словам. Пустые границы выгружают всю сохранённую историю; выбранные даты включаются целиком в UTC. Фильтр относится к началу тренировки, поэтому ответ после полуночи остаётся в тренировке предыдущего дня. Время в файлах ISO8601 UTC. Экспорт словаря и история имеют разные схемы; история предназначена для просмотра/анализа, обратный импорт оценок не добавляется.

## HTTP и данные

GET `/dictionary-export/history?kind=sessions|answers&from=YYYY-MM-DD&to=YYYY-MM-DD`, Bearer, private/no-store, attachment, nosniff. Опциональные даты проверяются как реальные календарные дни (1970–9998), from<=to; конечная граница — полночь следующего дня, exclusive. Неизвестные query-поля, владельцы и виды отвергаются. Config version1 добавляет `history:true`; frontend со старым backend скрывает новые кнопки.

- Sessions: format_version, session_id, started_at_utc, completed_at_utc, total_words, known_count, needs_review_count.
- Answers: format_version, session_id, started_at_utc, completed_at_utc, word_id, german, article, answer, answered_at_utc, word_available.

Одна строка на сессию/сохранённый ответ. Статистика сессии берётся из сохранённых счётчиков, а названия слов — из нынешних доступных карточек: снимков немецкого текста на момент ответа пока нет. Смена режима обучения в старой модели не сохранялась, поэтому выдуманной колонки режима нет. При удалении самой карточки её ответы удаляются существующим FK Cascade; суммарные счётчики сессии при этом могут быть выше числа доступных детальных строк. Уже отсутствующие записи экспорт восстановить не может.

Экспортируются только свои sessions/answers, включая историю после удаления слова из личного словаря или архивации. Если общая карточка теперь недоступна, ответ и время сохраняются в CSV, но id/название/артикль пусты и word_available=false. Даже ADMIN получает только свой экспорт; текст чужой частной карточки не читается. Чужие заметки, переводы, userId, email и auth-данные не запрашиваются.

Оба файла: UTF-8 BOM, разделитель `;`, CRLF, защита текстовых ячеек от Excel-формул как в CSV словаря. Header X-Wortkarten-Export-Version=1, X-Wortkarten-History-Kind, X-Wortkarten-History-Row-Count. До50000строк/25МиБ на файл; 413 предлагает сократить период. Пустой период без результатов возвращает корректные заголовки без данных. Не усекать историю молча.

RepeatableRead READ ONLY, страницы по1000 с курсором id, таймаут60сек и ограничения 3запроса/мин на аккаунт. Прогресс/SRS, даты ответов и карточки не меняются. Новых миграций/env/зависимостей нет. Frontend проверяет размер, тип, схему/вид/число строк; старый аккаунт и отменённый запрос не могут завершить скачивание после смены пользователя.
