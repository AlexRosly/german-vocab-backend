# Новая партия B1+ Brückenkurs — 08.11.2026

Источник: предоставленный владельцем Excel, 144 заполненные строки. Три пустые
строки исключены. Два повтора внутри списка объединены; Ausdruck разделён на
распечатку и языковое выражение с разными формами множественного числа.
Всего подготовлено143 карточки/значения. Проверка текущей БД переиспользовала13
существующих карточек; их содержимое, примеры и уроки не перезаписывались.

По поручению владельца атомарно добавлены130 новых карточек и130 оригинальных
немецких примеров,390 переводов слов и390 переводов примеров (ru/en/uk).
У всех новых карточек sourceBook=B1+ Brückenkurs, level=B1; исходный B1+ сохранён
в примечании, номер урока взят из списка. Две карточки относятся к уроку5,
74 — к уроку6,54 — к уроку7. Статус PENDING_REVIEW: публикация через модерацию.
Все новые слова сразу связаны с личным словарём владельца:915 карточек всего.
Общий каталог содержит916 карточек с учётом прежнего дополнительного Apfel.

Проверены: неизменность существующих строк всех17 таблиц в импорт-транзакции,
Google/EMAIL и ADMIN владельца, поля/примеры/три языка после commit. Текущие
контроллеры/сервисы на реальной БД выдали915 слов и все130 новых примеров для
каждого из ru/en/uk. Другой USER не получает личный словарь и не видит новые
pending-карточки в общей библиотеке. Это чтение сервисами, не браузерный OAuth.

Перед записью полная17-табличная копия восстановлена в PGlite; на ней проверен
тот же пакет и сохранность старых данных. После записи создана новая копия вне
Git и повторно восстановлена: SHA-256 всех17 таблиц совпали, CHECK личных книг
сохранён, перезапись непустой БД блокируется. Содержимое приватных копий в Git
не включено; автоматическое внешнее копирование этим этапом не настраивалось.

CLI-импортёр теперь принимает sourceBook через реальный CreateWordDto, по-прежнему
отклоняет подмену владельца/роли/публикации и личные книги. Проверки:17 import tests
и backend build PASS; frontend lint/build PASS. В локальном браузере с mock API
проверены четыре новые подсказки и создание обычным USER карточки с произвольной
книгой «Mein eigenes Lehrbuch». Эти тестовые данные не записывались в production.

Новые подсказки: A1.2 Schritte plus, A2.1 Schritte plus, A2.2 Schritte plus,
B1.1 Schritte plus. Источник — свободное поле до120 символов; новые названия
при создании доступны USER и ADMIN. После публикации общую книгу редактирует
ADMIN; дополнительные личные книги меняет владелец своего словаря.

Изменений схемы в этом этапе нет:14 прежних миграций. Для подсказок книг обновить
frontend на Render; сами130 новых карточек уже загружены в БД.

Уточнения форм при подготовке сверены, в частности, с
[Duden: Mangel](https://www.duden.de/rechtschreibung/Mangel_Defizit) и
[Duden: Rettungssanitäter](https://www.duden.de/rechtschreibung/Rettungssanitaeter).
Примеры составлены заново и не являются цитатами из учебника или словаря.
