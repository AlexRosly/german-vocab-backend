# Связанные карточки

`WordRelation` хранит двустороннюю тематическую связь, а не утверждение о полной синонимии. Одна пара ID хранится один раз в ASCII-порядке; self-link и обратные дубли запрещены БД.

- GET /api/v1/words/:id/relations — авторизация обязательна. И исходная, и целевые карточки проверяются по текущей видимости. Для USER доступны опубликованные и собственные карточки, для ADMIN — все. Ответ содержит selectedTranslation; отсутствующий перевод остаётся null.
- PUT /api/v1/words/:id/relations/:relatedId — только ADMIN, идемпотентное добавление.
- DELETE по тому же пути — только ADMIN, идемпотентное удаление.

Существующие notes не разбираются для определения связей. Связи не добавляют слова в личный словарь, не меняют прогресс и статус публикации. После снятия целевой карточки с публикации она пропадает из списка связей у других пользователей.

Миграция: 20261102120000_add_word_relations. Сначала миграция и backend, затем frontend. Публичный frontend умеет только просматривать связи; управление доступно через администраторский API. Импорт исходного большого Excel выполняется отдельными проверенными партиями.
