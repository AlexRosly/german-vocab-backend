## Обновление VPS

Миграция и содержимое уже в рабочей Neon. Не повторять импорт и не менять DATABASE_URL.
Обновить backend обычным процессом владельца в `~/apps/german-vocab-backend`:
`git pull --ff-only`, `npm ci --include=dev`, `npm run build`, затем перезапустить
только процесс Wortkarten с привычным именем PM2. Фронтенд Netlify обновляется
после push при включённом auto-deploy. До обновления backend клиент использует
совместимый основной `sourceBook`; дополнительные источники появятся после
выкладки нового backend.

Google Drive/cron: владелец сообщил об успешном ручном dump через Docker postgres:18,
архиве проекта, загрузке в Drive, ротации 7/30 дней и cron 03:30. Проверку
восстановления именно этой внешней копии он отложил. Локальные проверки выше
не означают приёмку Drive-копии, systemd/restic или мониторинга на VPS.
