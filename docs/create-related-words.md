# Связи при создании карточки — 03.11.2026

POST /words принимает необязательное relatedWordIds: до 20 уникальных ID существующих доступных карточек. Проверяются строковый формат ID, длина и отсутствие повторов. Недоступная или удалённая цель возвращает обычный 404 без раскрытия содержимого.

В одной Serializable-транзакции создаются слово PENDING_REVIEW, переводы, примеры, личная привязка автора и канонические двусторонние WordRelation. Все цели проверяются до записи. Если запись любой связи не удалась, транзакция откатывается целиком. Существующие карточки и членство других пользователей не меняются; новые цели автоматически не добавляются в личный словарь.

Приватность остаётся на чтении: автор видит свою ожидающую карточку и связи; другой пользователь не увидит её обратную связь на опубликованном слове до публикации. Отдельное изменение существующих связей через PUT/DELETE остаётся административным. PATCH /words/:id не принимает relatedWordIds; редактирование связей существующей карточки выполняется модератором.

Модель WordRelation уже существовала, новая миграция не нужна. БД/Neon этим этапом не изменялись. HTTP-регрессии проверяют создание/обратную видимость, недоступные цели, входные ограничения и откат ошибки; test:words — 73 теста. Дополнительно test:study — 57, backend build. HTTP-набор использует настоящий Nest и сервисы с подменённым Prisma, не PostgreSQL.
