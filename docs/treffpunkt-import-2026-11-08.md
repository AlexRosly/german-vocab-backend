## Проверки и текущие ограничения

Перед записью выполнены валидация текущими DTO приложения и пробный импорт в отдельную PostgreSQL-совместимую PGlite-базу. Рабочий импорт выполнен одной транзакцией со сверкой проверенной копии и сохранности всех прежних строк в 17 таблицах. Миграций не было.

После записи текущие скомпилированные controllers/services проверены на настоящей БД: 1113 личных карточек и 212 карточек Treffpunkt на каждом из RU/EN/UK, все новые примеры имеют выбранный перевод. Неопубликованные новые слова не выдаются в общей библиотеке обычному пользователю. Это проверка сервисов, не новый вход в браузере Render.

Полная итоговая копия вне Git проверена восстановлением в отдельной локальной базе: совпали хеши всех 17 таблиц. Прогресс, ADMIN и привязка Google сохранены. Расписание внешних резервных копий этой работой не настраивалось.

Одно слово сейчас имеет один общий уровень и номер урока. Поэтому 14 совпадающих карточек находятся по личной книге A1 Treffpunkt, но сохраняют свой прежний общий уровень/урок. Для одинакового слова в нескольких учебниках отдельные уроки каждой книги пока не моделируются. Kita, встретившаяся в двух уроках, имеет один основной урок и примечание о втором.

Массового добавления из библиотеки по книге/уроку и пользовательской загрузки Excel через интерфейс пока нет. Предлагаемый следующий шаг — добавить выбор книги/урока и действие «Добавить все найденные» с пропуском уже имеющихся карточек и сохранением прогресса.
