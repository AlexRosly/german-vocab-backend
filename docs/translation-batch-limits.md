# Лимит переводов — 03.11.2026

CreateWordDto и CreateWordExampleDto используют TRANSLATION_LANGUAGE_CODES.length вместо прежнего ArrayMaxSize(4). Сейчас разрешены до 11 переводов в одном запросе: ru/de/en/uk/pl/tr/ar/fr/es/it/pt. Ограничение автоматически следует каталогу; неизвестные языки и повторения после нормализации по-прежнему отклоняются.

Лимит применяется к созданию/обновлению слова, вложенным примерам, созданию/обновлению отдельного примера и валидации операторского импорта через те же DTO. Количество вложенных примеров остаётся ограничено 20.

Проверки: test:words — 69 тестов, включая HTTP-сценарии всех 11 языков при создании/обновлении и отрицательные случаи; node --test test/import-words.test.cjs — 16 тестов; npm run build. HTTP-набор использует подменённый Prisma, не живую Neon. Миграция не нужна, данные БД не изменялись.
