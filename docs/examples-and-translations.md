# Примеры при создании слова и независимые переводы

01.11.2026. Новая карточка и до 20 первых примеров создаются в одной Serializable
транзакции POST `/words`: при ошибке не сохраняются ни слово, ни личная связь,
ни переводы/примеры. `examples` допустим только в POST, не в PATCH слова.
Дальнейшее изменение примеров выполняется через существующий CRUD
`/words/:wordId/examples[/:exampleId]`, с прежними правами автора/ADMIN.

```json
{
  "german": "Gabelstapler",
  "article": "der",
  "grammaticalNumber": "singular",
  "translations": [{"language": "en", "text": "forklift"}],
  "examples": [{"german": "Der Gabelstapler transportiert Paletten."}]
}
```

Немецкое слово и немецкий текст непустого примера обязательны. Переводы
необязательны. `translations` слова и примера — независимые массивы
`{language,text}`, максимум 4 уникальных языка из `/languages` (ru/de/en/uk).
Текст NFC/trim, 1–1000 символов. На PATCH `text:null` удаляет только явно
названный язык; отсутствие языка в PATCH сохраняет его. Пустая строка и
отсутствующее поле text отклоняются. На POST null означает не создавать строку.
Legacy `translation` по-прежнему принимается как непустой русский перевод;
одновременное указание legacy и translations.ru отклоняется как неоднозначное.
Legacy Word.translation и WordExample.translation сохранены: без русского
перевода в них пустая строка, но фиктивные строки ru в таблицах не создаются.

WordTranslation и новая WordExampleTranslation имеют уникальность объекта/языка.
CRUD примеров возвращает translations и selectedTranslation по настройке
translationLanguage читающего пользователя. При отсутствии выбранного языка
text:null, без подстановки русского. Автоперевода нет. Модерация получает все
переводы примеров, их содержание включено в revision.

Проверка дубликатов сравнивает доступные карточки с той же немецкой формой,
артиклем, числом, множественным числом и заметками: совпадение перевода на общем
языке (либо прежнего русского поля) вызывает 409. При отсутствии переводов
сравниваются только карточки также без переводов. Разные значения и карточки
без общего языка не объединяются автоматически. Это не семантический поиск.

Миграция `20261101160000_add_example_translations` добавляет таблицу с FK cascade,
уникальным ключом exampleId/language и индексом language. Непустые существующие
WordExample.translation копируются как ru с сохранением текста и времён;
старые таблицы и поля не удаляются и не переписываются. Заметки не переносятся
в примеры автоматически. SRS, история и персональные связи не меняются.

Развёртывание: отдельно проверить и применить миграцию к согласованной демо-ветке,
затем Deploy backend, затем frontend. Build/start миграций не запускают.
Основную Neon main не менять без отдельного согласия. Старый frontend совместим
с новым API после миграции; новый frontend требует нового backend.
